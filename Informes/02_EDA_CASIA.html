Sub-etapa 1.2 · Obtención y preparación de datos: CASIA Gait Database (A, B y C)¶

Objetivo: revisar qué contienen las tres bases de siluetas de CASIA, comprobar que estén completas y en buen estado, y medir algo de la marcha directamente desde las imágenes.

Por qué se usan en el proyecto: CASIA no tiene etiquetas de riesgo de caída, así que no sirve para entrenar el clasificador. Sí sirve para la segunda etapa (cámara + MediaPipe): permite probar la extracción de la marcha desde imágenes con distintas personas, ángulos de cámara, ropa, carga, velocidad e iluminación [Yu, Tan y Tan, 2006].

2. Inventario¶

Cada carpeta que contiene imágenes .png se considera una secuencia. De su nombre se obtiene la base, la persona, la condición, el número de secuencia y el ángulo, usando estos patrones:

Base Ejemplo Patrón
B 001-nm-01-090-001.png persona-condición-secuencia-ángulo
A fyc-00_1-001.png o carpeta fyc/00_1 persona(letras)-ángulo_secuencia
C 001fn00...png o carpeta 001/fn00 persona + condición + secuencia

Con más de un millón de imágenes, este paso puede tardar uno o dos minutos.

PATRONES = [
    ("B", re.compile(r"(?P<persona>\d{3})-(?P<condicion>nm|bg|cl)-(?P<secuencia>\d{2})-(?P<angulo>\d{3})", re.I)),
    ("A", re.compile(r"(?P<persona>[a-z]{2,})[-_/\\](?P<angulo>00|45|90)_(?P<secuencia>\d)", re.I)),
    ("C", re.compile(r"(?P<persona>\d{2,5})[-_/\\]?(?P<condicion>fn|fb|fq|fs)[-_]?(?P<secuencia>\d{2})", re.I)),
]

def reconocer(ruta_relativa, nombre_archivo):
    for texto in (nombre_archivo, ruta_relativa.replace(os.sep, "/") + "/" + nombre_archivo):
        for base, patron in PATRONES:
            m = patron.search(texto)
            if m:
                d = m.groupdict()
                return {"base": base,
                        "persona": d["persona"].lower().zfill(3) if d["persona"].isdigit() else d["persona"].lower(),
                        "condicion": (d.get("condicion") or "nm").lower(),
                        "secuencia": int(d["secuencia"]),
                        "angulo": d["angulo"].zfill(3) if d.get("angulo") else "lat"}
    return None

def leer_cuadros(fila, maximo=None):
    # Devuelve la secuencia como arreglo (cuadros, alto, ancho) en escala de grises
    archivos = sorted(f for f in os.listdir(fila["ruta"]) if f.lower().endswith(".png"))[:maximo]
    cuadros = [cv2.imread(os.path.join(fila["ruta"], f), cv2.IMREAD_GRAYSCALE) for f in archivos]
    alto, ancho = cuadros[0].shape          # por si algún cuadro viene con otro tamaño
    return np.array([c if c.shape == (alto, ancho) else cv2.resize(c, (ancho, alto)) for c in cuadros])


def cuadro_central(fila):
    c = leer_cuadros(fila)
    return c[len(c) // 2]

6. Una primera medida de marcha desde la imagen¶

En la vista lateral la separación entre los pies crece y decrece con cada paso. Midiendo el ancho de la mitad inferior de la silueta en cada cuadro se obtiene una señal periódica; su autocorrelación entrega el período de un paso. Es el mismo principio que se usará con MediaPipe, pero sin necesitar la pose, así que servirá como referencia para comprobar que la cadencia que entregue MediaPipe es razonable.

En la base C se puede comparar además la cadencia entre marcha lenta, normal y rápida: es una buena prueba de que el método detecta cambios reales.

def ancho_piernas(m):
    # Ancho de la mitad inferior de la silueta en cada cuadro (en píxeles)
    anchos = []
    for cuadro in m:
        filas_on = np.where(cuadro.any(axis=1))[0]
        if len(filas_on) < 10:
            anchos.append(np.nan)
            continue
        alto = filas_on[-1] - filas_on[0]
        inferior = cuadro[filas_on[0] + alto // 2: filas_on[-1] + 1]
        cols = np.where(inferior.any(axis=0))[0]
        anchos.append(cols[-1] - cols[0] if len(cols) else np.nan)
    return np.array(anchos, float)


def periodo(senal):
    # Período (en cuadros) de la oscilación, con autocorrelación
    s = pd.Series(senal).interpolate().bfill().ffill().to_numpy()
    s = s - s.mean()
    if len(s) < 20 or s.std() == 0:
        return np.nan
    ac = np.correlate(s, s, "full")[len(s) - 1:]
    ac /= ac[0]
    picos = [k for k in range(4, len(ac) - 1) if ac[k] > ac[k - 1] and ac[k] >= ac[k + 1] and ac[k] > 0.2]
    return picos[0] if picos else np.nan

7. Resumen para el informe¶

  • Contenido: base A: 20 personas y 240 secuencias (100 % de lo esperado; 19 135 cuadros); base B: 124 personas y 13 593 secuencias (99,7 % de las 13 640 esperadas; 1 118 373 cuadros), con 47 secuencias faltantes repartidas en 8 personas; base C: 153 personas y 1 530 secuencias (100 %; 100 346 cuadros). No hubo carpetas sin reconocer ni secuencias repetidas.
  • Duración de las secuencias: mediana de 82 cuadros en A, 80 en B y 63 en C (unos 3,3, 3,2 y 2,5 s a 25 cuadros/s). Hay 59 secuencias con menos de 20 cuadros, demasiado cortas para contener un ciclo de marcha; se excluirán.
  • Calidad: en una muestra de 200 secuencias por base, el porcentaje de cuadros vacíos fue de 0 % en A, 0,09 % en B y 0,02 % en C, por lo que la segmentación de las siluetas es buena. Esos pocos cuadros se descartarán antes de estimar la pose.
  • Marcha desde la imagen: en vista lateral, la cadencia mediana fue de 115 pasos/min en la base A y de 125 pasos/min en la base B, valores normales para adultos. En la base C la cadencia cambió según la consigna: 125 pasos/min al caminar rápido, 115 al caminar normal y 94 al caminar lento. Esto muestra que el método detecta cambios reales en la marcha.
  • Limitación del método: como el período se mide en cuadros enteros, la cadencia solo puede tomar algunos valores (por ejemplo 125, 115 o 107 pasos/min). Para la etapa 2 se necesitará una medida más fina, como la que entregan los puntos de MediaPipe.
  • Uso en el proyecto: CASIA no tiene etiquetas de caída; se usará en la etapa 2 para probar la estimación de pose con MediaPipe en distintos ángulos, ropa, carga, velocidad e iluminación, no para entrenar el clasificador.
  • Limitación de la base: las personas de CASIA son en su mayoría jóvenes y sanas, no adultos mayores.
